# Ответы на вопросы

1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

Из-за принципиального различия в их архитектуре и способе хранения данных. Например, в git ветка - простой текстовый файл весом в 41 байт, который содержит хэш-ссылку на конкретный коммит, а в svn - полная копия директории проекта в репозитории; в git создание репозиторя происходит мгновенно, а в svn - требует сетевого запроса к серверу

2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет, в SVN нельзя сделать стандартный коммит без интернета или доступа к сети, потому что у него централизованная архитектура, происходит прямая отправка на сервер напрямую и отсутствует локальная база ревизий

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

SVN предпочтительнее в сценариях, где важны частичное скачивание структуры, строгий централизованный контроль доступа или работа с крупными не-бинарными проектными файлами
